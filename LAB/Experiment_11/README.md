# Experiment-11: Python Application Using AI Assistance

## Aim

To develop a simple Python application using **GitHub Copilot, Cursor, or Claude Code**.

## Algorithm / Procedure

1. Write the requirements.
2. Give the requirements to an AI tool.
3. Generate the Python code.
4. Run the program.
5. Check the output.

## Specification

Create a calculator that:

1. Takes two numbers.
2. Performs addition.
3. Performs subtraction.
4. Performs multiplication.
5. Performs division.

## Very Simple Python Program

```python
a = float(input("Enter first number: "))
b = float(input("Enter second number: "))

print("Addition:", a + b)
print("Subtraction:", a - b)
print("Multiplication:", a * b)

if b != 0:
    print("Division:", a / b)
else:
    print("Cannot divide by zero")
```
