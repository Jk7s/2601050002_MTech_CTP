##  Employee Bonus — Quick Sort

### Object

To sort the employees in **descending order of salary using Quick Sort** and identify employees whose salary is **₹50,000 or above** for a bonus.

### Algorithm

1. Start.
2. Store the employee names and their salaries.
3. Select the last employee's salary as the **pivot**.
4. Compare each employee's salary with the pivot.
5. For descending order, place salaries greater than or equal to the pivot on the left side.
6. Place the pivot in its correct position.
7. Apply Quick Sort recursively to the left and right portions.
8. Display the employees in descending order of salary.
9. Check each employee's salary.
10. If salary is **greater than or equal to ₹50,000**, select the employee as bonus eligible.
11. Display the bonus-eligible employees.
12. Stop.
